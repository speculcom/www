What changed on this site

Not a roadmap: changes already on disk, each with a page on the site.

OSS site + four sections

The OSS library becomes its own site: 135 repositories across 7 scenes, each with its own detail page and licence, language, star snapshot and last push. Data goes to 40 dataset cards and evals to 40 benchmarks on models; cloud compute to 8 providers on hardware; 12 tool categories are indexed on tools; prompts become a hub of 6 guides + 24 cases. The homepage now forks into use / build.

Nine homepages got data figures

Ecosystem map, six learn layers, 12 tool categories, model generations, memory–bandwidth scatter, paper topics, chain trust stack, directory health, and Playground use/source charts. All inline SVG, both themes.

Eight 2026 pages + ten 404s

One page each for models / hardware / papers / chain / tools / directory / Learn / Playground; all ten sites now have a 404, including OSS, instead of a blank dead end.

Learn glossary reaches 300

292 → 300: seven 2026 terms — AG-UI, MCP Apps, x402, ERC-8004, Agent Memory, Byteification and Agent Payments — plus the foundational Looped Transformer entry, each with sources and boundaries; GRPO, MLA, JEPA and Flow Matching keep standalone pages.

AI Directory rename and link health

“External sites” is now “AI Directory”; the mobile bar has ten items; dead links are no longer clickable.

Playground: 375 pieces across 31 model/experiment groups; source sets are no longer listed or given separate pages, with provenance noted only on each piece page; 15 run embedded or hosted here and 360 link out; unlicensed full files are not copied. The 2026-11 batch adds five pieces each from GLM-5.3, Qwen3.8-Max, MiniMax M3.1 Flash, Gemini 4 Argon, DeepSeek V4.1, Step 5 and Ornith 1.5, five each from Claude Opus 5.5, GPT-6.2 Astra and Gemini 4 Neon, five each from GPT-6.1 Terra, Grok 4.7, Claude Haiku 5.5 and MiMo V2.6 Pro, plus four from Hy4 flash, then five each from GPT-6 Astra, Claude Fable 5.1, Claude Sonnet 5.5, Muse Spark 1.3, Ox Alpha and Qwen3.8-27B, plus 24 mid-tail pieces and 11 official-media demo groups (GPT-6 Astra, Claude Fable 5.2, Gemini 4 Argon, Qwen4-Max, Kimi K3.1 Pro, Genie 4 and others). Its 2026 page and 404 are in place, with the shared ten-item mobile bar.
