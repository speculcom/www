Method and standards

This page explains how Specul content is made, how to read the confidence labels, and how errors are corrected. It applies to all ten sites.

How a piece of content is made

  1. Name the decision first. Write down the decision a reader needs to make, then decide whether the piece is worth publishing. If there is no real decision, it does not go in.
  2. Find a primary source. Official docs, specifications, papers, repository READMEs and product pages. Secondary coverage is used only when the primary source is unavailable, and it is labelled as such.
  3. Quote the source. For key specs, prices, licences and protocol status, copy one exact sentence into evidence instead of writing only the conclusion.
  4. Write the limits. Every entry answers “what does it not claim” and “when does it not apply”. No profile ships without that section.
  5. Run the gates. Field completeness, live links, number definitions, bilingual coverage, duplicates and orphan pages all run as scripts. If a gate fails, it does not ship.
  6. Date it honestly. Record the actual verification date and never relabel an old check as a new one. Out-of-date content stays up, marked “needs review”.

How to read the confidence labels

LabelMeaningWhat you can do with it
verifiedKey fields were checked against official sources and were reachable on the day.Use it for a first-pass shortlist; still check against your own case.
partialThe main facts have official sources, but fields such as price, quota and regional availability were not checked one by one.Good for comparing direction; confirm key numbers on the official page.
unknownThe source is missing, the page will not open, or the information contradicts itself.Treat it as a lead, not a conclusion.
Retired / deprecatedThe vendor explicitly ended the service, or the specification was deprecated.Do not use it for new work; it remains useful for historical comparison.

We will not relabel partial as verified to make the numbers look better. Without a fresh field-by-field check, the label stays as it is.
