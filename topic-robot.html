这一页不重复讲概念，也不给工具排名。它把全站已经写好的资料按做一个能动的机器人串起来：先定任务与运行环境，再找软件栈、模型与目录，最后核对结果。具体条件、来源和适用范围都在被链接的页面里。This page does not restate concepts or rank tools. It puts published material into the order in which a robot gets built: set the task and runtime, find the software stack, models and directories, then check the result. Conditions, sources and scope stay on the linked pages.

这一页的边界Scope of this page

Link order is not a ranking.
