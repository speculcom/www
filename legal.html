八、隐私与本地存储

8. Privacy and local storage

  • 本地存储：站点使用浏览器 localStorage 保存界面偏好——specul-lang（中/英）、specul-theme（明/暗），游戏内另有音量、按键等设置。这些数据只存在你的设备上，不会上传。
  • 匿名统计：specul.com 页面接入百度统计（hm.baidu.com），用于了解页面访问量等聚合指标。它不使用本站自有账号信息，我们不会据此识别个人身份。
  • 数据出售：我们不出售任何个人信息，也不建立用户画像。
  • 联机功能：部分演示支持 WebRTC 联机，房间信令经过部署方的中转服务；传输内容为对战数据，不含账号体系。
  • 如何拒绝：可通过浏览器的「阻止第三方脚本 / 广告拦截」或 Do-Not-Track 设置屏蔽统计脚本；清除站点数据即可删除本地偏好。
  • Local storage: UI preferences only (specul-lang, specul-theme, in-game volume/keys). Data never leaves your device.
  • Anonymous analytics: specul.com uses Baidu Tongji for aggregate page-view metrics; no personal identification.
  • No selling of personal information and no user profiling.
  • Netplay: some demos use WebRTC with a relay for room signalling; only match data is transmitted, with no account system.
  • Opting out: block third-party scripts or use Do-Not-Track; clear site data to remove local preferences.
