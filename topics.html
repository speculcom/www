路线顺序不代表推荐排名；没有实测的能力对比、成本降幅与成功率，站群一律写未知。Route order is not a ranking; where no measured comparison, cost reduction or success rate exists, the sites record it as unknown.

领域深读：把判断框架写完整Field guides: the full decision framework

路线页告诉你下一步看哪一页；领域深读把一件事拆成判断、做法、验收和失败分支。先看框架，再回到路线找具体资料。A route tells you which page to read next. A field guide turns a task into judgment, practice, acceptance and failure branches. Read the framework first, then return to the route for specific material.

  • 本地模型：先算清「跑得动」，再谈「跑得快」Local models: make it run first, then make it fast
  • 智能体：先把它当一条有权限的流程Agents: treat it as a permissioned process first
  • AI 视频：先写清验收标准，再选模型AI video: write the acceptance criteria before choosing a model
  • 语音与配音：先把一条链路跑通，再谈像不像真人Speech and voice: make one chain work before chasing a human voice
  • 音乐生成：先定交付物，再谈风格Music generation: fix the deliverable before the style
  • 图像生成：先定用途与验收，再选模型Image generation: fix the use and acceptance before the model
  • 评测：先证明这个分数能回答你的问题Evaluation: prove the score answers your question first
  • 办公与业务流程：先画流程，再选工具Work and business workflows: draw the pipeline before choosing tools
  • 机器人与具身：先跑通一条闭环，再谈人形Robotics: close one loop before building a humanoid
  • 信任评审：权限、数据流、权利、凭证分开看Trust review: permission, data flow, rights and provenance are separate
  • 中国区可用性：六列矩阵、数据驻留、许可与采购China availability: six-column matrix, residency, licence and procurement
