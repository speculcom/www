领域深度 · 图像与设计Field guide · Image and design

图像生成：从需求到一套能验收的图Image generation: from a brief to a set you can accept

你写了一句提示词，出来四张图，第一张很好看。但电商要六张同款、同一角度、带中文价签。海报要留标题区。角色要下一张还长得一样。图像任务不是“抽到一张好看的”，而是“交出一套能用的”。先写规格，再选模型。You type one prompt and get four images. The first looks great. But the shop needs six matching shots from the same angle with a Chinese price tag; the poster needs a title area; the character has to look the same in the next image. The job is not “get one good image”; it is “deliver a usable set”. Write the spec before choosing the model.

拿一个具体活走一遍One concrete job

假设一个具体活：给一款咖啡机做 6 张电商主图，1:1，带中文价签，机器颜色和角度要一致，背景可换。先写这五条，再决定用生成、编辑还是合成。Take one concrete job: six 1:1 product images for a coffee machine, with a Chinese price tag, consistent colour and angle, and a replaceable background. Write those five lines before choosing generation, editing or compositing.

1 · 先写图片规格，不要先写提示词1 · Write the image spec before the prompt

同一句提示词，用在电商主图、社媒封面、印刷海报和游戏贴图上，要求完全不同。主图要主体清楚、背景干净、比例固定。封面要留标题安全区。印刷要够分辨率与出血。贴图要透明底、边缘干净。先写用途与规格，才能判断一张图能不能用。The same prompt applied to an e-commerce hero, a social cover, a print poster and a game sticker has different requirements. A hero needs a clear subject, clean background and fixed ratio; a cover needs a safe area for the title; print needs enough resolution and bleed; a sticker needs transparency and clean edges. Write the use and spec first to judge whether an image is usable.

规格至少包含：用途、画幅比例、输出像素、是否印刷、色彩空间、是否需要透明、文字内容与位置、品牌色与字体、参考图、禁止元素、验收人。把这些写成一张表，生成、修图、排版和审核都看同一张表。The spec should include: use, aspect ratio, output pixels, print or screen, colour space, transparency, text content and position, brand colours and fonts, references, forbidden elements and approver. Put them in one table that generation, retouching, layout and review all read.

2 · 模型选择：生成、编辑、控制、放大2 · Model choice: generate, edit, control, upscale

图像工具至少分五类：文生图、图像编辑/局部重绘、结构控制、放大/修复、抠图/背景移除。它们可以来自同一家服务，也可以是不同工具。不要用“文生图模型”去完成所有任务。生成负责从无到有，编辑负责改局部，控制负责锁构图，放大负责输出尺寸，抠图负责交付格式。Image tools fall into at least five jobs: text-to-image, image editing/inpainting, structural control, upscaling/restoration, and cut-out/background removal. They may come from one provider or several; do not use a text-to-image model for every job. Generation creates, editing changes a region, control locks composition, upscaling reaches output size, and cut-out prepares delivery format.

模型选择还要看接入方式与许可：云端 API 省运维但数据会出本地。本地权重可控但吃显存、安装和调优。订阅制工具上手快但商用条款与输出权利要逐条读。先排除不满足许可或数据驻留要求的选项，再比较质量与成本。Model choice also depends on access and licence: a cloud API saves operations but sends data outside; local weights stay controllable but cost VRAM, setup and tuning; subscription tools are easy but commercial terms and output rights need reading. Eliminate options that fail licence or data-residency requirements before comparing quality and cost.

3 · 控制：构图、姿态、风格、局部3 · Control: composition, pose, style and region

控制手段的核心是“把不确定性放在该放的地方”。构图要固定，就用边缘、深度或线稿控制。人物姿态要固定，就用姿态骨架。风格要固定，就用参考图、LoRA 或固定模型。只改一个物体，就用蒙版局部重绘。控制越强，创意空间越小，这是交换，不是越多越好。The point of control is to keep uncertainty where it belongs. Lock composition with edge, depth or line control; lock pose with a skeleton; lock style with references, LoRA or a fixed model; change one object with a mask and inpainting. Stronger control leaves less creative room; that is a trade, not “more is better”.

种子、提示词、控制强度和参考图要一起记录。只记提示词，无法复现同一张图。只记种子，也无法解释为什么这次构图对了。把一次生成当作一次实验：变量、输入、输出和判断都留档。Record seed, prompt, control strength and references together. A prompt alone cannot reproduce an image; a seed alone cannot explain why the composition worked. Treat a generation as an experiment: variables, inputs, outputs and judgment are all logged.

  • 先锁画幅与构图：用边缘/深度/线稿控制，减少“生成后再裁”。Lock ratio and composition first with edge/depth/line control; avoid crop-after-generation.
  • 再锁主体：用姿态、参考图或蒙版，把不想变的部分固定。Lock the subject with pose, reference or mask; fix what must not change.
  • 最后调风格：固定模型/LoRA/参考，记录强度与种子。Adjust style last: fix model/LoRA/reference and record strength and seed.
  • 每次只改一个变量，保留上一版与参数。Change one variable at a time; keep the previous version and parameters.

4 · 一致性：角色、产品、场景4 · Consistency: character, product and scene

一套图最难的不是第一张，而是第十张还像同一个角色、同一个产品、同一个场景。角色一致性要固定脸型、发型、服装、年龄与表情范围。产品一致性要固定外形、比例、材质、logo 位置与光线。场景一致性要固定空间、时间、色调与镜头语言。只靠一句“同一个人”通常不够。The hard part of a set is not the first image but the tenth still looking like the same character, product and scene. Character consistency fixes face, hair, wardrobe, age and expression range. Product consistency fixes shape, proportions, material, logo position and lighting. Scene consistency fixes space, time, palette and lens language. “The same person” in a prompt is usually not enough.

可执行的做法：先做角色/产品设定板（正面、侧面、背面、细节、色板），再用参考图、固定种子、同一模型/LoRA、姿态控制和局部重绘。每张图都过同一张一致性检查表。生成后仍要用修图统一肤色、光线和边缘，不要假装模型一次就能全对。A workable method: build a character/product sheet (front, side, back, details, palette), then use references, fixed seeds, the same model/LoRA, pose control and inpainting. Run every image through the same consistency checklist. After generation, retouch skin tone, lighting and edges; do not pretend the model gets everything right in one pass.

5 · 文字与排版：模型最容易露馅的地方5 · Text and typography: where models show their seams

图像模型生成文字，尤其是中文、小字、长句和品牌字体，错误率仍然高：缺笔、错字、重复、字距不均、边缘糊。把文字当成“后期排版”而不是“生成内容”，通常更稳：生成不含文字的底图，留出安全区，再用设计工具排真实字体。Image models still make frequent errors in text, especially Chinese, small type, long lines and brand fonts: missing strokes, wrong characters, duplication, uneven spacing and soft edges. Treating text as a layout step rather than generated content is usually safer: generate a text-free base, leave a safe area, then set real type in a design tool.

如果必须让模型生成文字，至少做三件事：限定字数与语言、放大到 100% 逐字检查、把文字区与背景分开修。交付前再检查一遍拼写、标点、品牌名、价格和法务声明。这些错误比画面瑕疵更严重。If the model must generate text, do at least three things: constrain length and language, inspect every character at 100%, and retouch the text region separately from the background. Before delivery, recheck spelling, punctuation, brand names, prices and legal lines; these errors matter more than visual flaws.

判断句：品牌名、价格、法务声明不要交给图像模型直接生成。用真实字体排上去，再检查 100% 视图。Rule of thumb: do not let an image model render brand names, prices or legal lines. Set them in real type and inspect at 100%.

6 · 放大与输出：像素可以放大，细节不能凭空长出来6 · Upscaling and output: pixels can grow, detail cannot be invented

放大工具能提高像素，但不能把没拍到的细节变真。它可能补出更锐的纹理，也可能把头发、文字、产品边缘“猜”错。印刷前要区分“真实分辨率”和“放大后的分辨率”：前者决定细节，后者只决定文件大小。An upscaler can increase pixels but cannot make detail that was never captured true. It may add crisper texture, or guess hair, text and product edges wrong. Before print, separate “native resolution” from “upscaled resolution”: the first determines detail, the second only file size.

输出要按用途定：屏幕看 sRGB、72–96 ppi 的像素尺寸。印刷看实际尺寸、300 ppi 参考、出血与色彩空间。透明贴图看 alpha 边缘与预乘。游戏/网页看文件体积与格式。放大后检查边缘、文字、重复纹理和色偏，再决定是否回到更高分辨率重生成。Output depends on use: screen in sRGB at pixel dimensions for 72–96 ppi; print at physical size, a 300 ppi reference, bleed and colour space; transparent stickers with alpha edges and premultiplication; game/web with file size and format. After upscaling, check edges, text, repeated texture and colour shift before deciding to regenerate at a higher native resolution.

7 · 权利：模型、输入、肖像、商标、输出7 · Rights: model, input, likeness, trademark, output

图像的权利至少四层：模型/服务条款、训练数据与风格来源、输入参考图的权利、输出图的使用范围。模型允许商用，不代表参考图可以商用。输出图归你，也不代表图中的肖像、商标、建筑或艺术品可以随便用。Image rights have at least four layers: model/service terms, training data and style sources, rights in input references, and permitted use of output. A commercial model licence does not make a reference image commercial; owning the output does not make the likeness, trademark, building or artwork in it free to use.

高风险输入要单独处理：真人肖像、未成年人、公众人物、客户产品、品牌 logo、受版权保护的角色。需要同意、授权范围、期限与署名。有些平台还要求标注 AI 生成。保留生成日志、参考图来源和输出编辑记录，方便平台审核或下架。High-risk inputs need separate handling: real people, minors, public figures, client products, brand logos and copyrighted characters. They need consent, scope, duration and attribution; some platforms also require AI-generated labels. Keep generation logs, reference sources and edit records for platform review or takedown.

判断句：先把“模型许可、参考图许可、肖像/商标许可、输出用途”写成四行，再开始生成。任何一行写“未知”，都不要商用。Rule of thumb: write four lines — model licence, reference licence, likeness/trademark permission, output use — before generating. If any line says “unknown”, do not ship commercially.

8 · 验收：五张表，不靠一句“好看”8 · Acceptance: five tables, not one “looks good”

图像验收要分开看：提示词符合度、瑕疵率、一致性、文字准确率、品牌/审美、时间与成本。把它们合成一个“好看分”，会掩盖真正会返工的问题。比如一张氛围很好但 logo 变形的图，不能因为“好看”通过。Image acceptance separates prompt adherence, defect rate, consistency, text accuracy, brand/aesthetic fit, and time/cost. Collapsing them into one “looks good” score hides what causes rework. A moody image with a distorted logo does not pass because it is attractive.

验收样本要来自真实用途：同一角色十张、同一产品五个角度、同一版式三种尺寸、同一句文案中英文。评审至少两人，先盲评再对规格。把失败样本和参数保留下来，下一次生成才能收敛。Acceptance samples should come from real use: ten images of one character, five angles of one product, three sizes of one layout, one line of copy in Chinese and English. Use at least two reviewers, blind first and spec-check second. Keep failures and parameters so the next generation converges.

9 · 失败分支：先看错在哪里，再决定重生成还是修9 · Failure branches: locate the error before regenerating or editing

不是所有失败都要重生成。构图对、主体对、只是局部错，优先局部重绘。构图错、主体错，重生成更快。文字错，回排版工具。分辨率不够，先判断是原生不足还是放大瑕疵。每次只改一个变量，保留参数。Not every failure needs regeneration. If composition and subject are right and one region is wrong, inpaint first. If composition or subject is wrong, regenerate. If text is wrong, go back to layout. If resolution is short, decide whether native detail or upscaling is the issue. Change one variable and keep parameters.

Check: Character-by-character, real font

核对动作：与风格板并排比对Style drift
Fix first: Fix model/LoRA/reference
Check: Compare with style board

角色变脸
优先修法：设定板 + 参考 + 局部修
核对动作：十张并排盲测Identity drift
Fix first: Character sheet + reference + inpaint
Check: Blind-test ten side by side

先判断“能不能修”，再决定“要不要重生成”。重生成是最贵的一种修法。Decide whether it can be edited before deciding to regenerate. Regeneration is the most expensive fix.

10 · 最小落地路径10 · A minimum path to a deliverable image set

先做一张主图和一张最难的变体，不要一次生成二十张。主图验证规格与风格，变体验证一致性与文字。两张都过，再扩展到整套。Make one hero image and one hardest variant first, not twenty images at once. The hero validates spec and style; the variant validates consistency and text. Expand only after both pass.

  • 写规格表：用途、画幅、像素、文字、颜色、参考、禁区、验收人。Write the spec table: use, ratio, pixels, text, colour, references, exclusions, approver.
  • 先做一张主图：验证主体、构图、风格与输出尺寸。Make one hero: validate subject, composition, style and output size.
  • 再做最难的变体：换角度、换场景或加文字，检查一致性。Make the hardest variant: new angle, scene or text; check consistency.
  • 锁控制：固定种子、模型/LoRA、参考图与蒙版，记录强度。Lock control: fixed seed, model/LoRA, references and masks; record strength.
  • 文字后期排：生成无字底图，留安全区，用真实字体排版。Set text later: generate a text-free base, leave a safe area, use real type.
  • 按用途放大与导出：屏幕 sRGB、印刷 CMYK/出血、透明 alpha。Upscale and export by use: screen sRGB, print CMYK/bleed, transparent alpha.
  • 做一致性验收：十张并排、盲测、与规格逐项比对。Run consistency acceptance: ten side by side, blind, checked against spec.
  • 做权利表：模型、参考、肖像、商标、输出用途逐项记录。Build the rights table: model, reference, likeness, trademark, output use.
  • 保留参数与失败样本，下一次生成从记录开始，不靠记忆。Keep parameters and failures; start the next generation from records, not memory.
完成标准不是“出了几张好看的图”，而是：规格对、十张一致、文字可读、输出可用、权利可追溯。Done means the spec matches, ten images stay consistent, text is legible, output is usable and rights are traceable — not merely that a few images look good.
