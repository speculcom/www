方法与口径Method and standards

这一页说明 Specul 的内容是怎么做出来的、可信度标签怎么读、错了怎么改。它适用于全部十个站。This page explains how Specul content is made, how to read the confidence labels, and how errors are corrected. It applies to all ten sites.

一条内容的生产流程How a piece of content is made

  1. 定问题：先写「读者要做的决定」，再决定要不要写这条内容。没有决定场景的条目不收。Name the decision first. Write down the decision a reader needs to make, then decide whether the piece is worth publishing. If there is no real decision, it does not go in.
  2. 找一手来源：官方文档、规范、论文、仓库 README、产品页。二手解读只在找不到一手时使用，并标出来。Find a primary source. Official docs, specifications, papers, repository READMEs and product pages. Secondary coverage is used only when the primary source is unavailable, and it is labelled as such.
  3. 抄原文：关键规格、价格、许可、协议状态，必须从页面逐字摘一句，存进 evidence，不只写结论。Quote the source. For key specs, prices, licences and protocol status, copy one exact sentence into evidence instead of writing only the conclusion.
  4. 写边界：每条内容都要回答「它没主张什么」「什么情况下不适用」。没有这一段的档案不发布。Write the limits. Every entry answers “what does it not claim” and “when does it not apply”. No profile ships without that section.
  5. 过门禁：字段完整性、链接可达性、数字口径、双语覆盖、重复与孤儿页，全部跑脚本；失败就不发布。Run the gates. Field completeness, live links, number definitions, bilingual coverage, duplicates and orphan pages all run as scripts. If a gate fails, it does not ship.
  6. 标日期：写实际核验日，不改旧日期冒充复核。过期内容保留，但在页面上标出「待复核」。Date it honestly. Record the actual verification date and never relabel an old check as a new one. Out-of-date content stays up, marked “needs review”.

可信度标签怎么读How to read the confidence labels

标签Label含义Meaning你能拿它做什么What you can do with it
verified关键字段逐条对照过官方来源，且当天可达。Key fields were checked against official sources and were reachable on the day.可以直接用于选型初筛；仍要按自己的场景复核。Use it for a first-pass shortlist; still check against your own case.
partial主体信息有官方来源，但价格、额度、地区可用性等字段未逐项复核。The main facts have official sources, but fields such as price, quota and regional availability were not checked one by one.可以拿来比较方向；关键数字要回官方页确认。Good for comparing direction; confirm key numbers on the official page.
unknown来源缺失、页面打不开或信息自相矛盾。The source is missing, the page will not open, or the information contradicts itself.只当线索，不要当结论。Treat it as a lead, not a conclusion.
已停运 / 已废弃Retired / deprecated官方明确停止服务或规范废弃。The vendor explicitly ended the service, or the specification was deprecated.不要用于新项目；历史对照可以看。Do not use it for new work; it remains useful for historical comparison.

我们不会把 partial 直接改成 verified 来让数字好看。没有新一轮逐条核验，就保持原标签。We will not relabel partial as verified to make the numbers look better. Without a fresh field-by-field check, the label stays as it is.
