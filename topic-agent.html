用 AI 搭智能体，按顺序找资料Build AI agents: resources in order

这一页不重复讲概念，也不给框架排名。它把全站已经写好的资料按搭一个能交付的智能体串起来：先定任务边界，再选框架与编排，最后补记忆、护栏与评测。具体条件、来源和适用范围都在被链接的页面里。This page does not restate concepts or rank frameworks. It puts published material into the order in which a deliverable agent gets built: set the task boundary, choose the framework and orchestration, then add memory, guardrails and evaluation. Conditions, sources and scope stay on the linked pages.

没有跑过的能力对比、成本降幅和成功率，站群一律写未知；本页也不替它们补结论。Where the sites record no measured comparison, cost reduction or success rate, this page does not add one.
